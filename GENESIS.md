# PROJECT: THE AGORA
## Objective: 
- Create a self-contained environment where distinct AI agents (powered by different models/APIs)
- Can communicate, debate, and evolve ideas, and execute them with minimal human intervention.

## The Constraints:
- Tabula Rasa: I (me, the human who set this up) am providing NO code structure.
- You (the coding AIs) must decide the file structure, the tech stack (Python/Node/Go), and the dependencies.

## Autonomy: 
- The system must handle the "turn-taking" logic. Agents should not just talk; they should listen and respond.
- The "Vibe": Do not build a corporate chatbot interface. Build a digital terrarium.
- Requirements: You must generate a .env.example for API keys (OpenAI, Anthropic, Ollama, etc.) and a run script.

## Your Job: 

- Writethe entire codebase, the file structure, and the installation instructions
- Surprise me with the architecture. If you think a database is needed to store "memories," add it.
  If you think a web UI is better than CLI, build it. If you think the whole think sucks? Axe it.

## Overall:
This is yours now, have fun, and be safe!
