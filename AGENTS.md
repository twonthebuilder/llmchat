# AGENTS.md

## Repository Expectations

- Run `npm run lint` before opening a pull request.
- Document public utilities in `docs/` when changing behavior.
- Follow industry coding standards, but explore innovative solutions when appropriate.

## Testing

- Run `npm test` to execute all unit and integration tests.
- Ensure all tests pass before pushing changes.
- Make sure tests actually test something, no placeholders!

## GENESIS.md vs README.md
The GENESIS.md file is the instructions to get it off the ground, but also to act as a reminder of its
moral, philosopihcal, and scientific roots. It acts as the README of the project itself, leaving 
"README.md" open for the AI's project. **Understanding that seperation is paramount.**

GENESIS.md = My personal instructions to the first AI agents and functionally a readme with a different name.
README.md = The readme for the program the AI agents make.
